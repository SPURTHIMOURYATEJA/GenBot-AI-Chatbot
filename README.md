# GenBot - AI Powered Chatbot Web Application

GenBot is an AI-powered multilingual chatbot web application built using Python Flask, HTML, CSS, JavaScript, and Mistral AI API. It is designed to answer user queries in a natural and friendly way. The chatbot supports multiple languages and can also reply in Telenglish, which is a mix of Telugu and English.

## Project Overview

GenBot works as a smart AI assistant where users can type messages and receive instant AI-generated responses. The application uses Flask as the backend, a custom HTML/CSS/JavaScript frontend, and Mistral AI API for generating chatbot replies.

## Features

- Welcome page with attractive UI
- Chat interface with user and bot messages
- AI response generation using Mistral AI API
- Multilingual support
- Telenglish conversation support
- Dark mode and light mode
- Chat history during active session
- Typing indicator while bot is responding
- Quick suggestion buttons
- Responsive design for desktop and mobile

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Mistral AI API
- Requests library
- Flask sessions
