# GenBot – AI Chatbot Web Application
### Think Champ PV Ltd – Internship Mini Project

## 📌 Project Overview
A Flask-based AI chatbot web application with a beautiful, modern UI featuring Dark Mode, Chat History, and Quick Suggestions.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Python, Flask
- **Logic**: Pattern-matching ML (JSON-based responses)

## 📁 Project Structure
```
AI_Chatbot/
├── app.py              # Flask backend
├── chatbot.py          # Response logic
├── responses.json      # Predefined Q&A data
├── templates/
│   └── index.html      # Frontend UI
├── static/
│   └── style.css       # Styling
└── README.md
```

## 🚀 How to Run

### Step 1 – Install dependencies
```bash
pip install flask
```

### Step 2 – Run the app
```bash
cd AI_Chatbot
python app.py
```

### Step 3 – Open in browser
```
http://127.0.0.1:5000
```
